Support

Where to go depends on what isn't working: the app, or the SuperStation itself.

A problem with SS1 Tool

Something in SS1 Tool for Windows or Android doesn't work, doesn't fit your screen, or you can't reach a setting.

  • Android: in the app, open About › Report a problem with the app. It saves a report file (your phone's screen and settings, page layouts and screenshots, with addresses and names hidden) and opens a GitHub issue for you to attach it to.
  • Windows: open a new issue on GitHub and say which version you're using.
Open an issue on GitHub

App problems go to GitHub only, please, not the Taki Udon Discord. GitHub issues are public; you need a free GitHub account.

A problem with your SuperStation

The SuperStation, a core, a game, the picture or a controller isn't working right.

  1. In SS1 Tool, open Diag › Debug report and create a report.
  2. Save the file, then upload it yourself in the Taki Udon Discord's support channel, with a short description of what's wrong.
Taki Udon Discord

The Discord is run by Taki Udon's community, not by SS1 Tools.

Email

For anything that isn't a bug report, such as orders, refunds, privacy or the License Agreement: f3.digital.systems@gmail.com. Bug reports are quickest on GitHub, where the report file can be attached.
