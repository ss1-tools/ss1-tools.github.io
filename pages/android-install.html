Install SS1 Tool for Android

SS1 Tool for Android comes from this website, not the Play Store, so Android asks you to allow the install once.

  1. Buy the app on the Android page. You'll get an email with your license key and a download link.
  2. On your phone or tablet, open the download link and download SS1Tool-Android-x.y.z.apk.
  3. Open the downloaded file (from the download notification, or Files › Downloads).
  4. If Android says your browser or file manager isn't allowed to install apps, tap Settings, turn on Allow from this source, then go back.
  5. Tap Install. If Play Protect shows a warning about an app it doesn't know yet, tap More details and Install anyway. SS1 Tool for Android has no ads, trackers or access to your personal files. If Android says the app is blocked, see If Android blocks the install.
  6. Open SS1 Tool. Read and accept the License Agreement, then enter your license key. That's it. The app checks the key about once a week when you're online and keeps working without internet, but it needs to go online at least once every 30 days.

If Android blocks the install

Most phones install SS1 Tool with the steps above. Some show "App blocked" or "Blocked by Advanced Protection" instead, often when Advanced Protection is or was turned on, or on phones that block every app from outside the Play Store. This is Google's policy for apps from outside the Play Store (why SS1 Tool isn't on the Play Store), not a problem with the app. Use one of these two ways:

Option 1: Allow apps from unverified developers (on the phone)

  1. Open Settings › About phone and tap Build number 7 times (enter your PIN if asked). This turns on Developer options.
  2. Open Settings › System › Developer options and turn on Apps from unverified developers.
  3. Restart the phone. Android can take up to 24 hours before this takes effect.
  4. Install the APK again from your file manager or browser downloads.

Option 2: Install from a Windows PC with a USB cable

  1. On the phone, turn on Developer options (step 1 above), then in Settings › System › Developer options turn on USB debugging.
  2. On the PC, download Google's SDK Platform-Tools for Windows and unzip it.
  3. Download SS1Tool-Android-x.y.z.apk on the PC from your order, and put it in the platform-tools folder.
  4. Connect the phone with a USB cable and tap Allow when the phone asks to allow USB debugging.
  5. In the platform-tools folder, click the address bar, type cmd and press Enter. Then run (with your file's name):
    adb install -r SS1Tool-Android-x.y.z.apk
  6. When it says Success, SS1 Tool is installed. You can turn USB debugging off again. Updates can be installed the same way.
Check the download (optional). The email lists the file's SHA-256 checksum. On a PC, certutil -hashfile SS1Tool-Android-x.y.z.apk SHA256 shows it, so you can make sure the file is exactly the one we published.

Updating

Download the new version from the link in your purchase email (Lemon Squeezy also lets you get it again from your order) and install it over the old one, the same way. Your settings, saved devices and license stay as they are.

Moving to a new phone

Your key works on up to 3 devices. To free up a device you no longer use, open About in SS1 Tool on that device and choose Remove license from this device, or contact support.

Problems installing?

  • "App not installed": an older copy signed differently may be on the phone. Uninstall it first, then install again.
  • "There was a problem parsing the package": the download didn't finish; download it again.
  • Android older than 8.0: the app can't be installed; see supported versions.
  • Anything else: SS1 Tools support.
