SuperStation problems

My SD card got wrecked after running a "fix overlap" tool

Some SS1 cards came with fix_sd_overlap.sh / exfat_fix_overlap. It misreads the SS1's correct partition layout as overlapping, and running it can destroy the card (SuperStation-Documentation #14). Delete it: SS1 Tool's Setup page finds and removes it. If a card is already damaged, reflash it with the latest SuperStation installer, which has the fixed layout.

Console Mode, CRT output, WiFi or the ARM cores stopped working after an update

The September 7, 2026 MiSTer Linux update (kernel 5.15 to 6.18) broke Console Mode, CRT modes, WiFi and the ARM cores (3S-ARM, Duke3D, Quake) on the SS1. It has since been fixed. To stop Update All from replacing Linux without asking, set update_linux = false in downloader.ini. SS1 Tool's Setup › Update All sets this for you, and the status panel warns when a Linux update is waiting.

Update All crashes when I use the "Link" (chip-id) option

That option crashes on the SS1. Leave it off.

I see RTC errors when the SS1 starts

Run Update All. That fixes the RTC probe errors.

My SS1 reboots by itself, or has file system errors, with an NVMe drive

Gen 4 NVMe drives cause this. Use a Gen 3 drive.

Which power adapter should I use?

A single-port USB-C PD adapter that gives 9 V at 3 A. The Steam Deck adapter works. Don't share a multi-port charger with other devices, and don't use a Nintendo Switch 1 adapter.

I get no picture over HDMI from the dock

Plug the HDMI cable into the SuperStation itself. The HDMI-shaped port on the dock is an expansion port, not video out.

Windows asks to scan and fix my SD card

The card was switched off without being marked clean (exFAT's "dirty" flag). Shut down safely before switching off: SS1 Tool's Remote › Safe shutdown, or the shutdown.sh script it installs in the Scripts menu.

Can I turn off the dock's IR receiver?

Yes. It shows up as a USB device called "TinyUSB pico_ir_keyboard". Over SSH, find its port with grep -l pico_ir /sys/bus/usb/devices/*/product, then write 0 to that device's authorized file to switch it off (1 switches it back on). It comes back on at the next start unless you add the command to /media/fat/linux/user-startup.sh.

A core says "Unsafe Options" (PlayStation) or "Game Disc Is Unsuitable" (Saturn)

Reset that core's settings to their defaults in its OSD menu.

Update All warns about deprecated ini settings

Replace your ini files with the updated ones in Taki Udon's SuperStation-Documentation INI_Files. SS1 Tool backs up the old ones first if you do it from Setup › MiSTer settings.

Console Mode icons show dark grey where they should be black

Image editors often save PNGs with a colour palette plus gamma, sRGB or transparency information, and Console Mode mishandles those. Save your icons as plain truecolor (24-bit) PNGs without colour profile or transparency information.

Search and Favorites broke in a Console Mode nightly

Console Mode 1.1.3 nightly added a new setting (xySwap) that broke them. That's on Console Mode's side; 1.1.2 works.

Duke3D, Quake and 3S-ARM don't show up in Console Mode

They're missing from Console Mode's list of games it can launch (the _Other category). They still run from the MiSTer menu.

Video and DIP switches

Why does the SS1 have its own ini files? Did Taki change the video pinout?

No pinout change. The SS1 has a Sony CXA video encoder and four DIP switches for its analog output. Taki's MiSTer.ini differs from stock MiSTer only in vga_mode=subcarrier and video_info=2. His other ini files (RGHV, RGsB, SVID, YPbP) are profiles for the other kinds of output.

Which DIP switches go with which video mode?

For units made after December 2025. Region: Down = NTSC, Up = PAL. "–" means that switch doesn't matter for the mode.

Video modeDIP 1DIP 2DIP 3DIP 4
S-Video / composite, Sony encoder (subcarrier)RegionRegionDownUp
S-Video / composite, FPGA (svideo, cvbs)RegionRegionUpUp
Component (YPbPr)–––Down
RGB with separate sync (RGHV)–––Up
RGB, sync on green (RGsB)–––Down
Other RGB–––Up for SCART, Down for sync on green

What each switch does: 1 is the S-Video/composite region, 2 the FPGA luma trap, 3 picks the FPGA or the Sony encoder for S-Video/composite, and 4 is sync on green.

My S-Video or composite picture is black and white

Either vga_mode=subcarrier is set and the core has no subcarrier support, or the core is missing from yc.txt. Flip DIP 3 up and use the SVID profile.

How do I set up a PAL CRT?

Set menu_pal=1 in MiSTer.ini, flip DIP 1 up, and set each core to PAL in its OSD menu.

What does "Try it" in the video settings do?

It applies a video setting for a short time. Press Keep to keep it; if you don't, the old setting comes back by itself, so a setting that leaves you with no picture fixes itself. Just wait. Your MiSTer.ini is backed up before every try. In SS1 Tool it's on the Video page, and the Setup wizard there tells you which DIP switches to set.

How SS1 Tool works

What is SS1 Tool?

An app for Windows and Android that connects to your SuperStation over your home network (default login root / 1). It sets up a new card, edits the SS1's settings, moves files, backs things up, and runs diagnostics and debug reports.

Will it install or update my cores?

No. SS1 Tool never installs or updates cores by itself. Update All does that, when you run it.

Is it safe to let SS1 Tool change my settings?

Every fix takes a backup first, can be undone, and only runs when you press its button. The backups are kept on your PC or phone, one folder per ini file, with the date and time.

What does the "SS1 HDMI fix" do?

It comments out HDMI settings the SS1 doesn't support (HDMI-CEC, hdmi_off, video_off_logo). You can put them back any time.

What are "MiSTer & Linux backups"?

SS1 Tool keeps every version of the SS1's system files (MiSTer, the menu core, Linux and Console Mode) so you can put an earlier one back (Files › MiSTer & Linux backups). It's how you undo an update that broke something. Settings a Linux update can reset are listed separately, with the version from before.

Console Mode went back to the old version after updating

Console Mode keeps the old version until the new one has been confirmed running. Restarting, shutting down or reloading the menu before then puts the old one back. SS1 Tool confirms a waiting Console Mode update before it restarts, shuts down or reloads, and again when it connects.

What is Power watch?

A small watcher on the SuperStation (Diag › Power). It notices when the power was lost during heavy work (an update, a copy, a backup) and tells you, so you know which files to check.

Why does Samba need turning on?

It's off by default on MiSTer. Setup › Samba file sharing switches it on at every start, so the card shows up in Windows as \\IP\sdcard.

Windows SmartScreen warns about SS1Tool.exe

The exe isn't code-signed yet; signing is in progress. Choose More info › Run anyway.

The SSH terminal won't open

It uses Windows' own OpenSSH client. Add it in Windows Settings › System › Optional features.

Getting help

Where do I report a problem?

Problems with the SuperStation itself go to the Taki Udon Discord, with a debug report from Diag › Debug report. Problems with SS1 Tool go to GitHub issues or the SS1 Tool Discord. See Support.
